# Мои цели на семестр

1. Научиться уверенно работать с Git в терминале: ветки, rebase, разрешение конфликтов, без паники при ошибках.
2. Поднять и защитить собственный Linux-сервер (SSH по ключам, UFW, Nginx с HTTPS) и описать его настройку так, чтобы её можно было повторить по документации.
3. Собрать рабочий CI/CD-конвейер: автоматический деплой сайта из репозитория на сервер с проверкой результата.
