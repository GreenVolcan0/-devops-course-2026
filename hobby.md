# Мой пет-проект

Идея: телеграм-бот для учёта расходов: пользователь отправляет сумму и категорию, бот хранит записи и присылает недельную сводку.

Стек: Python (aiogram), SQLite, позже Docker

Цель: научиться упаковывать небольшое приложение в контейнер и автоматически выкладывать его на сервер через CI/CD.

## Сроки реализации

- Неделя 1: прототип бота с командами /add и /stats
- Неделя 2: хранение данных в SQLite
- Неделя 3: Dockerfile и запуск на виртуальной машине
