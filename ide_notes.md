# Git в VS Code и в терминале

## Что удобно в VS Code

1. Панель Source Control наглядно показывает изменённые файлы, а diff открывается одним кликом.
2. Встроенный редактор конфликтов с кнопками Accept Current / Incoming / Both.
3. GitLens показывает автора и дату каждой строки прямо в редакторе (удобный git blame).

## Что удобнее в терминале

1. Интерактивный rebase (`git rebase -i`), cherry-pick и reflog: в терминале видно, что именно происходит, а на сервере кроме терминала ничего нет.
